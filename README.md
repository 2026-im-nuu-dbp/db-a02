## 自行設計的內容說明(同學自填)

### 作品介紹

這是一個「圖文備忘錄平台」，特色為：

- 採用 Google 登入，減少帳號密碼管理負擔。
- 支援圖文備忘錄新增、編輯、刪除與垃圾桶還原。
- 支援使用者更新個人資料與管理員刪除使用者功能。
- 圖片上傳後自動產生縮圖，提高頁面載入效能。
- 管理員可在後台一覽全站使用者、備忘錄與登入紀錄，並查看個人資料變更紀錄。
- 系統可在重要操作後發送 Email 通知，例如資料更新與管理員操作。 

系統分兩個主要角色：

- 一般使用者：可以撰寫備忘、上傳圖片、管理自己的資料與備忘。
- 管理員：可查看全站資訊，包含使用者資料、備忘內容、登入紀錄，以及垃圾桶內容。

### 架構說明

此系統分為三個層級：

1. **資料庫層**
   - `databases.php`：建立資料庫連線，供所有 API 共用。
   - `init.sql`：建立使用者、登入紀錄與備忘錄資料表。

2. **前端頁面層**
   - `index.html`：Google 登入與新使用者資料補填。
   - `dashboard.html`：使用者主控台，管理個人備忘錄與垃圾桶功能。
   - `admin.html`：管理員後台，查詢全站資料與登入日誌。
   - `logout.html`：登出提示頁。
   - `css/style.css`：全站共用樣式。

3. **後端 API 層**
   - `api/auth.php`：Google 登入驗證與身份判斷。
   - `api/profile.php`：讀取與更新使用者個人資料，並支援變更紀錄。
   - `api/memo.php`：處理備忘錄新增、讀取、刪除、還原與圖片縮圖。
   - `api/admin.php`：管理員專用後端，提供全站資料查詢、使用者刪除以及變更歷程。
   - `api/mailer.php`：寄送 Email 通知，包含個人資料更新與管理員操作通知。
   - `api/logout.php`：登出流程與 session 清除。
   - `api/export.php`：資料表匯出功能。

### 互動流程概述

- 使用者在 `index.html` 使用 Google 登入，系統判斷是否為新用戶。
- 若為新用戶，系統引導補填基本資料，再進入 `dashboard.html`。
- 使用者在 `dashboard.html` 建立備忘錄時，`api/memo.php` 會保存文字內容、上傳圖片並生成縮圖，最後將資料寫入資料庫。
- 管理員在 `admin.html` 取得全站資料，`api/admin.php` 會回傳使用者清單、備忘錄與登入紀錄。

這樣的流程讓前端負責畫面呈現，後端負責驗證與資料處理，資料庫則負責儲存與查詢。
